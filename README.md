# GTA6 Radar

Portal independente de fã sobre Grand Theft Auto VI, com feed RSS de notícias, vídeos do YouTube, links para buscas de transmissões ao vivo e player de trilha sonora.

Projeto em HTML, CSS e JavaScript, com uma função serverless em `api/feed.js`, preparado para deploy na Vercel.

O projeto não é oficial e não tem vínculo com Rockstar Games ou Take-Two Interactive.
